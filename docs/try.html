Honesty first: this talks to the public demo network — a published membership secret and no durability promise; run your own nodes for anything real. Requests reach the nodes through this site's HTTPS gateway (one node's /fwd), because browsers refuse plain-HTTP from an HTTPS page — the gateway sees who talks to whom, which nodes always could; it reads nothing, which nodes never could. Reads after the first are answered from an in-page mirror. The client is one dependency-free file, byte-compatible with the reference and pinned to it by a cross-language test suite.
